# Historias de Usuario - PrestaLab

## Must Have

1. Como estudiante quiero actualización del material en tiempo real, para saber la disponibilidad del mismo.
2. Como Admin. lab, quiero revisar los préstamos, para tener control del equipo del lab.
3. Como estudiante, quiero solicitar material del lab, para utilizarlo en el laboratorio.
4. Como Administrador, quiero un inventario, para tener un control de él.

## Should Have

1. Como Administrador, quiero registrar un equipo disponible, para meterlo al inventario.
2. Como Administrador, quiero modificar la información del inventario, para mantener los datos actualizados.
3. Como Usuario, quiero consultar los materiales disponibles, para saber qué puedo pedir.
4. Como Usuario, quiero pedir un material, para usarlo.
5. Como Usuario, quiero consultar la fecha límite de devolución, para saber cuándo entregar el material.
6. Como administrador quiero saber el historial de movimientos, para saber qué alumno hizo mal uso del material y cobrar.
7. Como encargado de área/super. área, quiero saber el estado del material, para tener el material en buen estado.
8. Como estudiante, quiero devolver el material, para evitar un adeudo.
9. Como encargado, quiero un sistema para prestar material, para poder prestar material del lab.
10. Como estudiante, quiero pedir material para una práctica de laboratorio.
11. Como usuario, quiero una confirmación de que el material fue devuelto en tiempo y forma, para fundamentar que el material ha sido devuelto.
12. Como administrador, quiero acceso a todo el sistema, para mantenimiento del sistema.
13. Como Admin, quiero que el usuario no pueda registrar una devolución sin confirmarlo, para mantener el registro coherente. *(No Funcional)*
14. Como Admin, quiero respaldar la información, para no perderla en caso de emergencia. *(No Funcional)*
15. Como administrador, quiero envío automatizado de correos de confirmación, para formalizar los préstamos.
16. Como usuario, quiero que se me envíen notificaciones por correo de fecha de expiración de préstamo, para que no exceda la fecha límite.

## Could Have

1. Como Administrador quiero un historial, para modificar el inventario y si no es regresado, se cobra.
2. Como usuario quiero una vista de "carrito", para facilitar el proceso de préstamo haciéndolo más intuitivo y cómodo.
3. Como usuario quiero saber la cantidad de materiales disponibles, para decidir si aportar o no material.
4. Como Administrador, quiero un historial de préstamos, para tener trazabilidad de los materiales.
5. Como Usuario, quiero consultar los préstamos activos, para conocer qué materiales tengo.
6. Como jefe de laboratorio, quiero una notificación cuando se devuelva el material, para actualizar el inventario.
7. Como usuario, quiero tener un acceso seguro a mi cuenta, para que mi información sensible no tenga un mal uso.
8. Como administrador, quiero un registro de préstamos, para ubicar el paradero del equipo.
9. Como usuario, quiero una notificación, para saber si tengo aportado el material.

## Won't Have

1. Como estudiante, quiero acceso a mi historial de préstamos, para futuras aclaraciones y consultas.
2. Como administrador, quiero generar un reporte manual, para generar estadísticas y mejorar la toma de decisiones.

## Requisitos No Funcionales

1. Como Admin, quiero que el usuario no pueda registrar una devolución sin confirmarlo, para mantener el registro coherente.
2. Como Admin, quiero respaldar la información, para no perderla en caso de emergencia.
