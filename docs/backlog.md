# Historias de Usuario - PrestaLab


## Must Have


- Como estudiante quiero actualización del material en tiempo real, para saber la disponibilidad del mismo.

- Como Admin. lab, quiero revisar los préstamos, para tener control del equipo del lab.

- Como estudiante, quiero solicitar material del lab, para utilizarlo en el laboratorio.

- Como Administrador, quiero un inventario, para tener un control de él.


## Should Have


- Como Administrador, quiero registrar un equipo disponible, para meterlo al inventario.

- Como Administrador, quiero modificar la información del inventario, para mantener los datos actualizados.

- Como Usuario, quiero consultar los materiales disponibles, para saber qué puedo pedir.

- Como Usuario, quiero pedir un material, para usarlo.

- Como Usuario, quiero consultar la fecha límite de devolución, para saber cuándo entregar el material.

- Como administrador quiero saber el historial de movimientos, para saber qué alumno hizo mal uso del material y cobrar.

- Como encargado de área/super. área, quiero saber el estado del material, para tener el material en buen estado.

- Como estudiante, quiero devolver el material, para evitar un adeudo.

- Como encargado, quiero un sistema para prestar material, para poder prestar material del lab.

- Como estudiante, quiero pedir material para una práctica de laboratorio.

- Como usuario, quiero una confirmación de que el material fue devuelto en tiempo y forma, para fundamentar que el material ha sido devuelto.

- Como administrador, quiero acceso a todo el sistema, para mantenimiento del sistema.

- Como Admin, quiero que el usuario no pueda registrar una devolución sin confirmarlo, para mantener el registro coherente. *(No Funcional)*

- Como Admin, quiero respaldar la información, para no perderla en caso de emergencia. *(No Funcional)*

- Como administrador, quiero envío automatizado de correos de confirmación, para formalizar los préstamos.

- Como usuario, quiero que se me envíen notificaciones por correo de fecha de expiración de préstamo, para que no exceda la fecha límite.


## Could Have


- Como Administrador quiero un historial, para modificar el inventario y si no es regresado, se cobra.

- Como usuario quiero una vista de "carrito", para facilitar el proceso de préstamo haciéndolo más intuitivo y cómodo.

- Como usuario quiero saber la cantidad de materiales disponibles, para decidir si aportar o no material.

- Como Administrador, quiero un historial de préstamos, para tener trazabilidad de los materiales.

- Como Usuario, quiero consultar los préstamos activos, para conocer qué materiales tengo.

- Como jefe de laboratorio, quiero una notificación cuando se devuelva el material, para actualizar el inventario.

- Como usuario, quiero tener un acceso seguro a mi cuenta, para que mi información sensible no tenga un mal uso.

- Como administrador, quiero un registro de préstamos, para ubicar el paradero del equipo.

- Como usuario, quiero una notificación, para saber si tengo aportado el material.


## Won't Have


- Como estudiante, quiero acceso a mi historial de préstamos, para futuras aclaraciones y consultas.
	- 

- Como administrador, quiero generar un reporte manual, para generar estadísticas y mejorar la toma de decisiones.


### Justificación


Estas funcionalidades no son necesarias para la operación básica del sistema de préstamo e inventario en la primera versión, por lo que se propone incorporarlas en futuras iteraciones del proyecto.


Aunque las estadísticas y reportes aportan valor para la gestión y la toma de decisiones, su implementación puede posponerse sin afectar las operaciones principales del sistema.


## Requisitos No Funcionales


- Como Admin, quiero que el usuario no pueda registrar una devolución sin confirmarlo, para mantener el registro coherente.

- Como Admin, quiero respaldar la información, para no perderla en caso de emergencia.
